HTML Basics Guide

Learn the building blocks of the web. See the code on the left, and watch how the browser brings it to life on the right!

1. Text Formatting

Use <b> to make text thick and bold, and <i> to make it slanted (italic).

<b>This text is bold!</b>

<i>This text is italic!</i>
This text is bold!

This text is italic!

2. Subscript & Strikethrough

<sub> drops the text slightly lower. <del> draws a line right through the text to show it's deleted or changed.

Water is H<sub>2</sub>O.

Old Price: <del>$99</del>
Water is H2O.

Old Price: $99

4. The Moving Tag

<marquee> is a classic, fun HTML tag that makes whatever is inside it scroll automatically! (Note: Web developers don't use this anymore, but it's great for learning).

<marquee>
  Look at me go! 🚀
</marquee>
Look at me go! 🚀

5. Links & Images

Use <a> for links (Anchor). It needs an href attribute to tell it where to go.

Use <img> to show pictures. It needs a src attribute for the image link.

<!-- A Link -->
<a href="#">Click me!</a>

<!-- An Image -->
<img src="https://images.unsplash.com/photo-1514888286974-6c03e2ca1dba?w=200&h=150&fit=crop" >
Click me!

6. Tables

Tables use a team of tags: <table> is the box, <tr> is a Row, <th> is a bold Header, and <td> is normal Data.

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>25</td>
  </tr>
</table>
Name Age
Alice 25
Bob 30
