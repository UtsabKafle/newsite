How They Compare

Postal Address Part IP Address Part Purpose
Country / State Nepal / Bagmati ↔ Network ID 192.168.0.0/16 Identifies the overall network (like a country)
City Kathmandu ↔ Subnet 192.168.1.0/24 Narrows down the location (like a city)
Street Address House 10 ↔ Device ID 192.168.1.1 Identifies the specific device (like a house)
ZIP Code 44600 ↔ Port Number :80 Directs to the right service (like a postal code)

An IP address uniquely identifies a device on a network, just like a postal address uniquely identifies a building.
