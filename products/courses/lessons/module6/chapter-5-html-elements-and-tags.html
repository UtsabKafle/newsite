Chapter 5

HTML Elements and Tags

Understanding the building blocks of a webpage

Introduction

An HTML Element is the fundamental building block of a webpage. Every Element is defined by Tag that tell the browser how to display the content inside them. Most Element have an opening Tag, content, and a closing Tag.

Element can be nested inside each other like Russian dolls, creating the hierarchical structure of an HTML document. Inline Element sit within lines of text, while Block Element create sections that stack vertically.

In this chapter, you will learn the most common HTML Element, how to structure them, and how Attribute add extra meaning.

How It Works

HTML Tag surround content to give it meaning. A <strong> Tag makes text bold and signals importance. An <em> Tag adds emphasis (italics). A <div> Tag groups content into a block container. Tag can be self-closing (like <br> for a line break) or container Tag (like <p>...</p>).

Everyday Object Analogy

Think of HTML Element as LEGO bricks. A <div> is a large base plate, <h1> is a tall brick for a title, <p> is a standard brick for text, and <img> is a sticker piece. You stack and arrange bricks to build a complete structure.

Common HTML Tags

Headings

<h1> to <h6> define six levels of headings, with <h1> being the most important and <h6> the least.

Text Tags

<p> for paragraphs, <span> for inline text, <strong> for bold, and <em> for italics.

Container Tags

<div> for block sections and <span> for inline grouping. These are generic container Element.

Block vs Inline Elements

Block Element

Start on a new line and take up the full width available. Examples: <div>, <h1>, <p>, <ul>, <table>. They create the main structure of a page.

Inline Element

Sit within Block Element and only take up as much width as their content. Examples: <span>, <a>, <strong>, <img>. They style or mark up parts of text.

Deeper Dive

Attribute provide additional information about Element. The class Attribute assigns a CSS class for styling, id gives a unique identifier, src specifies the source of an image, and href defines the destination of a link. Attribute are always placed inside the opening Tag.

Key Insight

Void Element (also called self-closing Tag) have no content and no closing Tag. Common Void Element include <img>, <br>, <hr>, and <input>. They carry all their information in Attribute.

Advanced

HTML Element can be categorized by their content model: flow content (most Element that go in the body), phrasing content (inline text-level Element), sectioning content (headers, footers, navs), and embedded content (images, videos, iframes). Understanding these categories helps you write valid, semantic HTML.

Custom Data Attribute (prefixed with data-) allow developers to store extra information directly in HTML that JavaScript can access. For example, <button data-user-id="123"> stores the user ID for a click handler without using hidden Element.

Vocabulary Table

TermDefinition
ElementA complete HTML unit consisting of an opening tag, content, and closing tag.
TagThe markup keyword enclosed in angle brackets that defines an element type.
AttributeAdditional metadata placed in the opening tag to configure an element.
Block ElementAn element that starts on a new line and fills the available horizontal space.
Inline ElementAn element that sits within a line of text and only takes up the width of its content.
Void ElementA self-closing element with no content or closing tag, such as <img>.
NestingPlacing one HTML element inside another to create a hierarchical structure.
<div>A generic block-level container used to group elements for styling or layout.
<span>A generic inline container used to style or manipulate small sections of text.
Data AttributeA custom attribute prefixed with data- that stores extra information in HTML.

Fun Facts

The <div> Tag is the most used HTML Tag in the world. Almost every modern webpage has dozens or hundreds of <div> Element.

The <a> Tag (anchor) is what makes the web a "web" — it creates hyperlinks that connect pages together.

The <hr> Tag creates a horizontal line and originally stood for "horizontal rule" in early web design.

A single HTML file can have multiple <h1> Element, but using only one per page is recommended for accessibility and SEO.

The comment Tag <!-- comment --> allows developers to leave notes in code that are invisible to users but helpful for future edits.

Knowledge Check

1. Which of the following is a void (self-closing) element?

Answer: <img>

2. What is the difference between a block element and an inline element?

Answer: Block elements start on a new line; inline elements stay within the line

3. How do you write a comment in HTML?

Answer: <!-- comment -->
