Explorer Pack

Foundational discovery for the next generation

A foundational journey into technology — from understanding how the internet works to building your first programs and robots. No prior experience needed.

Class 5 – 7 Beginner 10 Modules

Pack Overview

Each module is a full session with theory, demonstrations, and practical activities designed for young learners taking their first steps into technology.

Request full syllabus See Builder Pack →

Learning Approach

Built for curious minds

Visual Simulations

Interactive demos for every module — see how things work, not just read about them.

Hands-On Activities

A4 paper assignments, website tasks, and physical activities for every single module.

Creative Assignments

Unique tasks after every module — dramas, games, builds, and experiments.

What students will explore

Module 01

How Internet Works

Packets, DNS, servers, and the invisible infrastructure of the web.

Module 02

How Computers Work

Input, process, output — the fundamental cycle that powers everything.

Module 03

Computer Assembly

Learn to assemble and disassemble a computer. Know every part by name and function.

Module 04

CPU Components

Inside the brain of the computer — ALU, control unit, registers, and how they work together.

Module 05

How Apps Work

Behind the screens: frontend, backend, databases, and how apps talk to each other.

Module 06

Building Websites

Made from scratch — HTML, CSS, and the basics of making things live on the web.

Module 07

How Robots Work

Sensors, logic, and simple automation — the building blocks of robotics.

Module 08

Scratch Programming

Block-based coding that makes programming visual, fun, and immediately rewarding.

Module 09

Blockchain Tech

Decentralized ledgers, digital trust, and how blockchain changes how we keep records.

Module 10

Mini Projects

Creative paper tasks and hands-on builds that bring everything together.

Creative Assignments

These are experiences — designed to make learning stick through drama, games, building, and experimentation.

01

Binary Name Encoding

Encode and decode your name into binary — understand how computers see text.

02

Message Delivery Drama

Perform an act showing how a message travels through networks, routers, and cables.

03

Password Cracking Demo

A physical demonstration of brute-force and dictionary attack methods.

04

Custom Encryption System

Design your own encryption method — become a cryptography engineer for a day.

05

Algorithm Demonstration

Create and demonstrate algorithms used in real apps and blockchain through role-play.

06

Programming Concepts Explained

Creative explanations of functions, variables, and loops in your own unique way.

07

Smart Light System

Build a smart light using an LDR sensor and LED — your first real hardware project.

08

Responsive Webpage Origami

Learn responsive design through a creative origami folding activity.

09

Basic Webpage Design

Design and build your very first webpage from scratch — and see it live.

10

Blockchain Transaction Game

Track a network's transactions as a node — see consensus in action.
